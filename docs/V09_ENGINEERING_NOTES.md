# FieldSec v0.9 Engineering Notes

## Release theme
Adaptive Instruction & Target Correlation.

## Capability preservation rule
FieldSec is additive. A richer workflow must not silently delete a simpler workflow, lesson, parser, evidence class, or field instrument. Advanced skill levels change default presentation and recommendations, not capability availability.

## Skill profile
- Beginner: definitions, setup, safety, observation-vs-inference.
- Intermediate: baselines, hypotheses, evidence quality, structured findings.
- Advanced: session intelligence, contradictory evidence, target correlation, traceability.
- Expert/Field: concise operational guidance, efficient validation, reporting and retest discipline.

Adaptive Guidance can be disabled at any level to show the fuller instructional presentation. Existing v0.8 state files are migrated as setup-complete and preserve the prior workflow. New installs open Settings first so the learner can select a starting level.

## Target correlation
The Adaptive Learning Path uses target type, interfaces, MAC/BSSID metadata, lesson completion, and practice count to recommend a next learning sequence. Recommendations do not authorize active testing and do not assert vulnerabilities.

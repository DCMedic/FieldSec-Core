# FieldSec v0.10 Engineering Notes

v0.10 adds a five-domain proficiency matrix and cross-domain target relationship rendering without removing any v0.9 workflows. Overall skill remains as a convenient baseline; domain skills can diverge for Hardware Security, Wireless Security, NFC/RFID, Evidence/Reporting, and IoT Threat Modeling.

The Target Relationship Graph is an analytical context view. It links target identity, interfaces, services, OBS, HYP, FND, and RT record classes conceptually but must not imply causality or vulnerability from mere proximity or correlation.

Capability preservation remains mandatory: v0.10 retains all v0.9 modules, lessons, workbenches, record types, target intelligence, capstone workflows, and legacy report compatibility.

# v0.10 Domain Skill Matrix

FieldSec stores an overall profile plus independent domain proficiency levels:

- Hardware Security
- Wireless Security
- NFC/RFID
- Evidence/Reporting
- IoT Threat Modeling

Each uses Beginner, Intermediate, Advanced, or Expert/Field. A domain level changes explanation density, checkpoints, and recommended sequencing. It never hides or disables an underlying capability.

A learner can therefore be Advanced in hardware analysis while remaining Beginner in credential systems, without needing a separate application or losing access to either domain.

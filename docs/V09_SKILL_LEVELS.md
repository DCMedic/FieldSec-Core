# Skill Levels and Adaptive Instruction

FieldSec teaches the same underlying professional workflow at every level. Skill selection controls scaffolding, vocabulary, detail, and recommended sequence.

## Beginner
Full explanations, wiring/setup guidance, safety reminders, definitions, and interpretation checkpoints.

## Intermediate
Less terminology scaffolding; stronger emphasis on baselines, falsifiable hypotheses, evidence references, impact validation, and remediation.

## Advanced
Focus on session comparison, contradictory evidence, cross-interface correlation, traceability, and choosing the least-invasive sufficient test.

## Expert / Field
Concise operator presentation. The full beginner/intermediate lesson content remains available by disabling Adaptive Guidance.

## Non-regression principle
A level never hides or deletes a capability from the application package. It only changes default instructional presentation and the recommended learning path.

# FieldSec 1.0.0 Release Notes

FieldSec 1.0.0 is the first release milestone.

## Core platform
- Persistent engagement, scope, authorization acknowledgement, targets, and target intelligence.
- Beginner, Intermediate, Advanced, and Expert/Field profiles plus five independent domain skill levels.
- Adaptive learning path and adaptive curriculum without capability gating.
- Capability Preservation Contract retained.

## Live workbenches
- UART: receive-only capture, text/hex view, history, extracted strings.
- I2C: address-presence scan, baseline comparison, topology history.
- Wi-Fi Developer Board: passive survey telemetry, BSSID change comparison, channel/security history.
- GPIO: passive non-mutating one-second digital monitor of the external GPIO connector pins with history logging.

## Assessment reasoning
- OBS, HYP, ANN, JRN, IFC, SVC, FND, and RT record families.
- Competency Engine.
- Guided Assessment Planner.
- Target graph, workspace, instructor review, capstone, and after-action review.

## Reporting
- Desktop Markdown report generator.
- Evidence-to-finding-to-retest traceability.
- Legacy export tolerance retained.

## Release status
Source-release complete. Physical hardware acceptance remains required before calling a specific Flipper/Developer Board installation production-validated.

# Migration to FieldSec 1.0

## From v0.9/v0.10

Do not delete the FieldSec app-data directory before upgrading. v1.0 retains the existing state and CSV/log file names. Domain skill migration introduced in v0.10 remains intact.

Recommended process:
1. Back up the entire FieldSec app-data directory from the microSD card.
2. Install the v1.0 FAP over/alongside the existing external application according to the firmware tool being used.
3. Launch FieldSec.
4. Confirm engagement, target, overall skill, five domain skills, and Academy progress.
5. Open Evidence Timeline, Hypotheses, Findings, and Retest views to confirm historical records.
6. Run Export Summary and compare with the backup before deleting the backup.

## Fresh install

A fresh installation starts in the skill/adaptive setup view. Beginner + Adaptive Guidance is the safe default, but every capability remains available regardless of selected level.

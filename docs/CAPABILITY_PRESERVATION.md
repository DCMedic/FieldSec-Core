# FieldSec Capability Preservation Contract

FieldSec releases are additive by default. New abstractions may wrap earlier functions, but earlier useful capability should remain reachable unless removal is required for safety, hardware incompatibility, or a documented upstream API break.

Protected capability families through v0.9:
- Engagement, scope and authorization metadata
- Multi-target database and target intelligence
- UART receive-only workbench, history and string extraction
- I2C presence/topology workbench and history
- Passive Wi-Fi Developer Board survey and history
- GPIO instructional framework
- 15 assessment/training modules
- 8 Academy lessons and persistent progress/practice
- OBS/FND/RT traceability
- Hypotheses, journal, annotations, interface/service map
- Capstone, after-action and instructor review
- Desktop reporting and legacy export compatibility

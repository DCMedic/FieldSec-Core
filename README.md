# FieldSec 1.0.0

FieldSec is a skill-adaptive handheld cybersecurity education and authorized field-assessment environment for the Flipper Zero, with a companion firmware target for the official Wi-Fi Developer Board.

## First-release goals

- Teach beginners through expert/field users without hiding lower-level learning material.
- Preserve capabilities as the project grows.
- Couple real observations to evidence, hypotheses, findings, remediation, and retests.
- Prefer passive or least-invasive observation first.
- Preserve older FieldSec data formats when practical.

## v1.0 highlights

- 15 assessment modules and 8 persistent Academy lessons.
- Overall plus per-domain skill profiles and adaptive curriculum.
- UART receive-only workbench, I2C address-presence workbench, passive Wi-Fi Developer Board workbench, and non-mutating GPIO snapshot.
- Targets, target profiles, relationship graph, interface/service inventory, hypotheses, annotations, journal, evidence timeline, structured findings, retests, capstone, instructor review, competency engine, and assessment planner.
- Desktop report generator and Developer Board parser.

Start with `docs/RELEASE_RUNBOOK.md` for build, install, hardware validation, and first-release acceptance steps.
